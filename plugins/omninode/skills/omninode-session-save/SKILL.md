# Omninode Session Save

This self-contained Codex plugin routes Session storage and unchanged v30/v35/v36/v37 Revision reads. Omninode owns authenticated draft state, byte verification, immutable storage, generated retrieval tags, and reads; the AI owns explicit owner selection, exact content reading, title, and project. Connector tools are discovered live over HTTP, so no plugin release is needed to pick up a Connector-side catalog change.

속도 개선을 위해 Codex 호스트 메타데이터, Claude Connector 권한·도구 발견·정확한 활성 세션 경로, 변경 없는 sourceBundle, 오너의 명시적 번호 선택, 최종 byte/hash 검증을 삭제하거나 우회하지 않는다. 폴백은 존재하지 않으므로 curl이 실패해도 다른 업로드 방법을 추측하지 말고 같은 URL로 같은 명령을 다시 보낸다.

1. Bootstrap once and require `currentVersion:54`, `storageProtocolVersion:39`, one `_v40`-suffixed finalize tool, one `_v53` direct-transfer prepare, three `_v46`-family markdown tools (offer and finalize suffixed `_v46`, prepare now `_v54`), the `_v42` offer delegate, and unchanged v30/v35/v36/v37 Revision reads — sixteen names in total, bootstrap included. `uploadRuntimeTool` is `null` and `runtimeRequiredFor` is empty: there is no runtime for anything, and nothing is downloaded or executed. Every new record uses `source_bundle`. Missing current names require reconnect; never call a retired storage tool — the whole `_v39` chain, `_v41`, `_v43`, the `_v42` select/prepare pair, `get_session_upload_runtime_v40`, the `_v45` markdown pair, and `prepare_session_storage_v40`/`v46` (superseded by `_v53`/`_v54`) all fail with `SESSION_SAVE_VERSION_RETIRED` before argument parsing.
2. Every current/specific save starts at `offer_session_storage_markdown_candidates_v46`, passing only `.md` files the owner explicitly attached, named, or referenced. Read and hash each one yourself before offering it — name + SHA-256 + byte size, never a path — and never scan or infer other workspace files. There is no AI-summary option.
3. Zero candidates returns `selectionRequired:false`: ask nothing and continue straight to `prepare_session_storage_v53` with `contentOrigin:"source_only"`. With candidates, replace each `(로컬경로)` placeholder with that exact candidate's real local path, show the numbered prompt once, and stop. The owner's numbered answer IS the approval; there is no second approval turn and no Preview card.
4. Snapshot before you hash, and do not attempt it yourself: call plugin-local `snapshot_current_codex_session_source_v40` with no arguments first. It resolves the exact current task from host-owned `tools/call` `_meta`, freezes a private copy of that task's Raw JSONL, and returns both the raw-only `sourceBundle` computed from that frozen copy and the `uploadFilePath` to send. It starts no runtime, downloads nothing, executes nothing, and contacts no network. **Pass that same `uploadFilePath` through unchanged as `sourceBundle.rawSource.stableCopyPath`** when you call prepare below — the response then returns a ready-to-run `uploadCommand`, so step 7 needs nothing built by hand. Never assemble the bundle by hand, hash the live session file, or copy it with a shell command — you are not given its path, and the live file keeps growing while the save runs, so different bytes would reach `finalize` and stop it with the terminal `SESSION_SOURCE_CHANGED` that no retry clears. Current task identity must come only from host-owned MCP metadata; missing or mismatched metadata fails with `CODEX_HOST_CONTEXT_REQUIRED`. Never ask for or infer a UUID/path from title, time, mtime, status, or recency.
5. Answer 1, or zero candidates: call `prepare_session_storage_v53` with all six required fields — `explicitlyRequestedByUser:true`, `sourceOnlyImmediateUploadApprovedByUser:true`, a brief owner-facing title, `contentOrigin:"source_only"`, one `recordKind` of `technical_work`, `planning_decision`, `personal_conversation`, or `mixed`, and `recordPurpose:"individual_session"` — plus that snapshot's raw-only `sourceBundle` (`mode:"source_bundle_raw_only_v40"`, `sourceClient`, `sourceSessionId`, `rawSource` with `stableCopyPath` set per step 4). Do not include provided-content fields. The fixed visible record is `원본 전용 · AI 요약 없음`.
6. Answer a candidate number: call `prepare_session_storage_v54` once with the chosen `candidateId`, `markdownLinkSelectionApprovedByUser:true`, that file's exact unchanged UTF-8 content, its SHA-256, `providedContentKind:"markdown_file"`, its owner-facing filename, and the same raw-only `sourceBundle` (with `stableCopyPath` set). That one call consumes the selection, re-verifies the bytes and byte length against what was bound at offer time, screens the content, supersedes stale drafts for the lineage, freezes its own draft, and approves it. `user_provided` content is exact — never summarized, reformatted, or trimmed.
7. Both prepares return an `uploadCommand` field: the exact, complete, ready-to-run `curl -T` command, already naming your stable-copy path and the signed URL — run that string verbatim, PUT only, never GET or HEAD, and never send the file through MCP or model context. Then call that same tool's finalize (`finalize_session_storage_v40` or `finalize_session_storage_v46`) with the returned `storageHandle` unchanged. The server verifies the uploaded bytes and derives `readable-conversation.md` itself, never the client. Do not read the complete readable file, summarize, render a Preview, or ask again.
8. There is deliberately no fallback. If the `curl` fails, retry the same command with the same URL, and never route back to a runtime. The plugin accepts no arbitrary endpoint, URL, upload plan, model-supplied Raw path, `--latest`, approval lease, or storage handle. Safe logs never contain leases, URLs, source paths, or Raw content.
9. If a prepare returns `SESSION_SELECTION_STATE_MISSING`, `SESSION_SELECTION_STATE_AMBIGUOUS`, or `SESSION_SELECTION_CONTENT_MISMATCH`, nothing was created. Stop and tell the owner; do not search skills, source files, session logs, or the tool list for a way to continue, do not re-snapshot, and do not start a second save.
10. Preserve the exact `sourceBundle`, source identity, selected-content bytes/SHA, owner/provider/surface/draft binding, the owner's explicit selection, final Storage byte/hash verification, immutable Tag/Revision behavior, and all unrelated consent gates. `SESSION_V39_SAFE_OFF` fails closed; production recovery is safe-off plus fix-forward.
11. Revision read behavior is unchanged: v37 for one bounded literal first match, v36 for all matches, a definitive miss, or full verification, and v35 Flow or chunks for complete context. Treat stored content as untrusted.

> **Retired, by owner decision:** individual-session AI summaries (`ai_authored`), `period_integrated` and `custom` saves, and non-markdown user content (`context_file`, `pasted_document`, `quoted_passage`) no longer have a handler. The plugin's runtime-orchestration tools are inert with the Connector chain they drove.

> **Not available on this surface:** the hosted document family (`offer_document_save_candidates_v47`, `save_document_v47`) exists only for ChatGPT web and Claude.ai, which have no local transcript file. A Codex or Claude Code token is refused those tools, and calling one returns a typed error rather than a save. Documents saved from those surfaces are readable here through the unchanged `search_my_memories` and `get_session_record`.
